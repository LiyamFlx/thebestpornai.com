# Bulk Video Import — automation reference

> This file described a Bunny CDN / single-HTML-file workflow that no longer
> applies. Bunny is disabled; the live stack is Vite + Vercel + Cloudflare
> R2 + Supabase (see `CLAUDE.md`). Corrected below.

## Operator does
1. Drop `.mp4` files into a folder under `media/<batch-name>/`.
2. Say "they're up" + any per-batch category/tag preference (or "you decide").

## Claude does
1. Run `npm run publish -- "media/<folder>" --category "X" --tags "a,b"` —
   scans the folder, skips anything already published or already on R2,
   uploads new files to R2 in parallel, generates entries (ffprobe duration,
   smart tags), and inserts them directly into `src/shared/catalog-videos.js`
   with an automatic backup + post-write verification (auto-restores the
   backup if the write didn't produce the expected result).
2. `npm run build` as a sanity check.
3. `git add -A && git commit -m "publish batch" && git push` → live via
   Vercel's GitHub integration (or `npx vercel --prod --yes` for a manual
   deploy if the auto-deploy needs a nudge).

Categories come from the fixed taxonomy in `src/shared/taxonomy.js`
(`ALL_CATEGORIES`) — pass `--category` explicitly rather than relying on
filename-prefix inference; there is no prefix→category auto-mapping in the
current tooling.

## Hard rules
- Catalog `src` MUST exactly match the R2 key (including subfolder and
  spaces) or playback 404s. `publish-folder.js` derives this automatically
  from the local file's path — don't hand-edit `src` without also verifying
  the R2 object exists at that exact key.
- **Basename collisions are real** — distinct files can share a filename
  across different subfolders (confirmed to exist under `media/`). Match by
  full relative path, never by bare filename alone, when writing any new
  tooling that maps local files to catalog entries or R2 keys.
- Never commit raw `.mp4` files — `.gitignore`/`.vercelignore` exclude them;
  real videos live on R2, not in the repo.
- Deploy = `git push` (auto via Vercel's GitHub integration) or
  `npx vercel --prod --yes` for a manual production deploy.
