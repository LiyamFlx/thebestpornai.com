# Bulk Video Import — automation reference

Workflow for adding videos to StreamHub. See CLAUDE.md for the deploy mechanics.

## Operator does
1. Upload .mp4 files to Bunny storage (file manager), grouped by prefix.
2. Say "they're up" + any per-batch preference (or "you decide").
3. At the end: purge Pull Zone cache (dashboard).

## Claude does (A-Z, automatic)
1. List Bunny storage → get EXACT filenames (don't trust numbering; catch failed uploads).
2. Map each file's prefix → category (table below).
3. Generate varied title + 3 tags per video.
4. Add any new category to DATA.categories in all 4 files so every video gets a feed row.
5. Insert entries (unique ids, continue from current max) into:
   viewer/viewer-app.html, manager/platform-manager.html,
   creator/creator-studio.html, _data.js.
6. Verify every CDN URL returns 200 (https://streamhub-media.b-cdn.net/<urlencoded>).
7. Upload the 4 HTML files to Bunny storage (deploy). Commit to git.
8. Tell operator to purge cache; then screenshot-verify live.

## Prefix → category map (extend as new themes arrive)
- cumshot / comshot     -> Cumshot
- Amazing Ass / ass     -> Big Ass
- MILF                  -> MILF (add category)
- Asian                 -> Asian
- Teen / 18             -> 18-25
- Blond / blonde        -> Blond
- big tits / big natural-> Big Tits (add category)
- AI / grok / robo      -> AI
- threesome             -> Threesome
- anal                  -> Anal
- POV                   -> POV
- (no match)            -> Amateur, or spread across POV/Amateur/Babe

## Hard rules
- Catalog `src` filename MUST exactly match Bunny filename (spaces included) or it 404s.
- Every `category:"X"` used by a video MUST be in DATA.categories or it won't render
  on the home feed. Add missing categories automatically.
- Keep the videos:[] array identical across all 4 files.
- Never commit raw .mp4 (they live on Bunny).
- Deploy = upload HTML to Bunny storage (NOT git push — live site is Bunny, not Vercel).
- Cache purge is mandatory after deploy (30-day TTL).
