# media/

Video files are **not** tracked in this repository (see `.gitignore`).

Drop your `.mp4` files here named `exemple-1.mp4` … `exemple-9.mp4`
(or update the `src` paths in [`../_data.js`](../_data.js) to match your own
filenames). All three apps read videos from this folder.

Without videos present, the apps still run — players and thumbnails simply
show the placeholder/gradient fallback.
